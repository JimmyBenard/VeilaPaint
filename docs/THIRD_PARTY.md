# Composants et assets

Les logos Veila Paint, l’icône V et l’image Nuvora Studio sont les fichiers fournis pour ce projet. Leurs droits restent ceux de leurs titulaires. Aucun nouveau logo n’a été généré.

Dépendances principales : Kotlin, kotlinx.coroutines, Jetpack Compose, AndroidX Activity/Lifecycle/Core, Media3 Transformer/effect 1.6.1 (licences Apache 2.0), Android Gradle Plugin et Gradle (Apache 2.0). Tests : JUnit 4 (EPL 1.0), Robolectric (MIT), AndroidX Test (Apache 2.0). Se reporter aux fichiers de licence publiés avec chaque dépendance pour les avis complets. Les dépendances de test ne sont pas des fonctions de production.

Le SDK Android et le JDK sont nécessaires pour construire mais ne sont pas inclus dans l’archive. Les fichiers ont été formatés avec ktfmt 0.57 (Apache 2.0) ; cet outil n’est pas une dépendance de l’application.
